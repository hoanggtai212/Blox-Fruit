# BloxFruitsLike-Roblox

A small Roblox RPG starter project inspired by the genre of anime-style fruit/power games.
This project uses original names and simple placeholder systems.

## Features
- Player level, EXP, and Coins
- Server-side combat damage
- Simple enemy/NPC health system
- Power fruit pickup and basic ability
- RemoteEvents for client/server communication
- Basic HUD
- DataStore save/load template

## Setup
1. Open Roblox Studio and create a new Baseplate.
2. Copy the scripts from `src` into the matching Roblox services.
3. For DataStore testing in Studio, enable **Game Settings > Security > Enable Studio Access to API Services**.
4. Replace placeholder enemy models and map content with your own assets.

## Folder mapping
- `src/ServerScriptService` -> ServerScriptService
- `src/ReplicatedStorage` -> ReplicatedStorage
- `src/StarterPlayer/StarterPlayerScripts` -> StarterPlayer > StarterPlayerScripts
- `src/StarterGui` -> StarterGui

This is a starter source project, not a complete commercial game.
